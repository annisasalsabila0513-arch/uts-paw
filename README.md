## Fitur

- Manajemen Koleksi Buku (Tambah, Lihat, Detail, Hapus)
- Penyimpanan data lokal menggunakan LocalStorage dan Context API
- Halaman statistik jumlah item per kategori
- pencarian dan filter berdasarkan kategori

## Menjalankan secara lokal
```bash
cd app
npm install
npm run dev
```

## Konsep React yang dipakai

- Komponen fungsional dan React Router untuk navigasi multi-halaman.
- State Manajemen menggunakan useState, useEffect, dan Custom Hooks.
- Pengelolaan form terkontrol dengan validasi input dan penanganan error.
